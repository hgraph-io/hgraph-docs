# GraphQL Assistant (Deprecated)

The Hgraph GraphQL Assistant has been replaced by the **AI Data Agent**.

The AI Data Agent offers a more powerful experience for exploring Hedera data with natural language—no coding required. It's powered by the Hgraph MCP Server.

**[Try the AI Data Agent →](https://hgraph.ai)**
